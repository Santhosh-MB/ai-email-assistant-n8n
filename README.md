# 📧 AI Email Assistant using n8n & Google Gemini

## Overview
This project is an AI-powered email automation workflow built using **n8n**, **Google Gemini**, and the **Gmail API**. It automatically retrieves Gmail messages, generates professional AI-powered email replies, and creates Gmail drafts.

## Features
- 📩 Fetch emails from Gmail
- 🤖 Generate AI-powered email replies using Google Gemini
- 📝 Automatically create Gmail drafts
- 🔐 Secure OAuth 2.0 authentication
- ⚡ No-code workflow automation using n8n

## Workflow

Manual Trigger
↓
Gmail (Get Messages)
↓
Google Gemini (Basic LLM Chain)
↓
Gmail (Create Draft)

## Technologies Used
- n8n
- Google Gemini
- Gmail API
- OAuth 2.0
- Workflow Automation

## Project Description
Built an AI-powered email automation workflow using n8n, Google Gemini, and the Gmail API. The workflow retrieves Gmail messages, generates professional AI-powered responses, and automatically creates Gmail drafts. This project demonstrates API integration, OAuth authentication, AI workflow automation, and no-code development.
